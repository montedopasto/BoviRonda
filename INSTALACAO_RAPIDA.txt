BOVIRONDA — INSTALAÇÃO RÁPIDA

1. Google Drive > criar Google Sheet vazia.
2. Extensões > Apps Script.
3. Colar Code.gs.
4. Executar setupBoviRonda() uma vez.
5. Implementar como Web App e copiar o URL /exec.
6. Editar config.js e colar esse URL em API_URL.
7. Importar os ficheiros da raiz para um repositório GitHub.
8. Ativar GitHub Pages.
9. Primeiro login: admin / 1234.
